# iindev

IT-решения для бизнеса. Сайты, AI-автоматизация, SEO.

## Почему такое название

**Иинд** — из якутского языка. Выражение "Инник диигин да" (инник диигин да) — "типа значит так говоришь". В фильме [Кэскил](https://www.kinopoisk.ru/film/1007496/) это локальное якутское кино — фраза превратилась в шутку/стёб. "Ииндиинда" — сокращение. Когда говоришь что-то нелепое и добавляешь "иинд" или "ииндиинда" — типа шутка, не воспринимай всерьёз.

**iindev** = **iin** (иинд) + **dev** (development). Игра слов.
